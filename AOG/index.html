Telepítés · Install

  1. Ha a Windows SmartScreen figyelmeztet: További információ → Futtatás mindenképp. · If SmartScreen warns: More info → Run anyway.
  2. A ZIP-et csomagold ki egy mappába (ne futtasd a ZIP-en belülről). · Extract the ZIP to a folder (do not run from inside the ZIP).
